# INC-004: Adobe Acrobat Installation Request

## Summary

User requested Adobe Acrobat to be installed on their workstation. Ticket was submitted through Freshservice, resolved remotely via RDP, and closed after confirming functionality with the user.

- **Ticket ID:** INC-004
- **Category:** Software Installation
- **Priority:** Low
- **Requested by:** Behnam Masoumi
- **Assigned to:** Ben Masoumi – Help Desk
- **Tool used:** Freshservice (ticketing), RDP (remote access)

## Steps Taken

1. Reviewed the ticket and confirmed the request was submitted by the account owner (not a third party requesting on someone else's behalf), to rule out a social engineering attempt before granting remote access.
2. Checked with their manager to confirm the request was authorized, then confirmed with the user that they were okay with the workstation being briefly unavailable during installation, in case anything time-sensitive was coming up.
3. Verified the user's device met the minimum requirements for Adobe Acrobat.
4. Connected to the user's machine via RDP.
5. Downloaded and installed Adobe Acrobat on its official website.
6. Confirmed the application launched successfully and the user could open a test PDF.
7. Logged off the RDP session.
