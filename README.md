# INC-001 — User Password Reset

## Ticket Summary

An employee, **Steve**, submitted a ticket after being away from work for an extended period and forgetting his password. He reported that the issue was **not urgent**, but requested that it be resolved sometime during the day.

**Category:** Account / Password

**Priority:** Medium

**Assignee:** Ben Masoumi and helpdesk@ben.local

**Status:** Closed

## Troubleshooting & Resolution

1. Located Steve's account in **Active Directory**.
2. Reset the user's password.
3. Enabled **"User must change password at next logon"** to ensure Steve creates his own password after signing in.
4. Added an **internal note** documenting the resolution for the IT team.
5. Sent a **public response** to Steve confirming that the issue had been resolved.
6. Closed the ticket after completing the request.

## Result

The password was successfully reset and the user was instructed to create a new password upon their next login.
